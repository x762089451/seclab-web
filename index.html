学习路线 ROADMAP

      
按顺序走，别跳阶段。左侧是阶段，右侧是该阶段必须装好的工具。

    

  


  

    

      
STAGE 011-2 个月

      

        
基础打底 · 计算机与网络

        
目标：看懂一个请求从浏览器到服务器的全过程，能自己搭一台虚拟机靶场。

        
    
          
  • 操作系统：Windows 进程/服务/注册表、Linux 文件权限与常用命令
    • 
          
  • 网络：TCP/IP、HTTP 协议、DNS、代理与抓包原理
    • 
          
  • 编程：Python 基础语法 + 简单脚本；HTML/JS/SQL 能读能改
    • 
        

        

          VMwareKaliPythonWiresharkDVWA
        

      

    


    

      
STAGE 022-3 个月

      

        
Web 渗透 · 主战场

        
目标：独立完成一次授权渗透，能出报告；在公益 SRC 上交出第一个可复现的低危。

        
    
          
  • OWASP Top 10 原理与手工验证：注入、XSS、SSRF、越权、文件上传
    • 
          
  • Burp Suite 全流程：抓包、改包、重放、Intruder、插件
    • 
          
  • 信息收集：子域枚举、指纹识别、目录扫描、旁站与端口
    • 
        

        

          BurpsqlmapnucleifscanXraydirsearch
        

      

    


    

      
STAGE 032-3 个月

      

        
内网渗透 · 权限提升

        
目标：拿下 Web 权限后能横向到域控；理解域环境攻击链（这阶段只在自己的靶场练）。

        
    
          
  • Windows 提权、Linux 提权、权限维持思路
    • 
          
  • 域基础：Kerberos、LDAP、ACL、票据、委派
    • 
          
  • 隧道与代理：Chisel / frp / 正向反向连接
    • 
        

        

          MetasploitImpacketBloodHoundNetExecMimikatzChisel
        

      

    


    

      
STAGE 04长期

      

        
进阶方向 · 选一条深挖

        
目标：形成个人技术标签 —— 能写工具、能分析样本、能讲清一次完整攻击链。

        
    
          
  • 逆向与恶意代码分析：IDA / Ghidra / x64dbg / Frida

  • 取证与应急响应：Volatility / Autopsy / 时间线分析
    • 
          
  • 免杀、代码审计、云安全、工控安全（择一深入）

          Ghidrax64dbgjadxVolatility3Autopsy

    06
    

      
合规与免责 LEGAL

      
技术本身中立，使用方式决定性质。

    

  

  

    

      
✔ 可以做

      
    
        
  • 自己的设备、自己的虚拟机、本地靶场
    • 
        
  • SRC 平台明确列入范围且允许测试的资产（先读规则）
    • 
        
  • 书面授权的渗透测试项目，按授权书限定强度与时间
    • 
        
  • 学习协议原理、复现公开 CVE（在本地漏洞环境）
    • 
      

    

    

      
✘ 不能做

      
    
        
  • 对未授权站点扫描、爆破、拖库、上传 webshell
    • 
        
  • 把别人的漏洞报告 / 漏洞盒子公开 PoC 当自己的成果提交
    • 
        
  • 使用破解版、捆绑后门的"集成工具包"
    • 
        
  • 在 SRC 项目上跑全端口扫描器、批量爆破（多数平台直接判违规）
    • 
      

    

  

  

    《中华人民共和国刑法》第二百八十五条、二百八十六条：非法侵入、获取、控制计算机信息系统，及提供侵入工具，均可能构成犯罪。
    未授权测试的后果不是"被发现就删站"，而是刑事风险 + 平台永久封号 + 报告作废。
